BIENVENIDO AL PROYECTO GESTARIAN

Este paquete contiene toda la información necesaria para comprender y
desarrollar GESTARIAN.

GESTARIAN NO es una aplicación sencilla.

Es una plataforma profesional de gestión empresarial que nace a partir
de un proyecto piloto desarrollado en Microsoft Excel VBA denominado
DM CAR.

El objetivo NO consiste en convertir el archivo Excel en una aplicación.

El objetivo consiste en ANALIZAR el sistema actual y RECONSTRUIRLO con
una arquitectura moderna, escalable y preparada para evolucionar durante
años.

================================================================================

ANTES DE ESCRIBIR UNA SOLA LÍNEA DE CÓDIGO
